# ApplyTrack

A modern job application tracking platform that helps students and professionals organize every stage of their job search from one place.

🔗 Live Website: https://applytrack-tau.vercel.app/

---

## Features

- Dashboard with application overview
- Track job applications through every hiring stage
- Resume management
- Analytics and insights
- Calendar & task reminders
- Company management
- Modern dark UI
- Responsive design

---

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Prisma ORM
- SQLite
- Vercel
